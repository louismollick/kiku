# Custom Kanji Info Extra

Change the order or hide some sections in kanji popup.

The `sections` object includes `CommonWords`, `VisuallySimilar`, `ComposedOf`, `UsedIn`, `Meanings`, and `Related`. Render `sections.CommonWords()` to include Common Words in a custom layout. It appears only in the Kanji Tooltip.
